# EOH Controller — Phase 5/6

Универсальный HUB для регистрации и настройки нескольких Eye of Harmony.

## HUB

Запуск:

```lua
lua /home/hub/main.lua
```

Главный экран:

- `1-9` — открыть конфигурацию выбранного зарегистрированного EOH.
- `S` — Setup / регистрация или переназначение оборудования.
- `R` — перечитать registry.
- `U` — запуск обновления.
- `Q` — выход.

## Экран конфигурации EOH

Позволяет изменять и сохранять в `registry.dat`:

- профиль работы: обычный Production / Production + AA / Power Deep Dark;
- тир планеты (1-8 для Production);
- оверклоки 0-3;
- Auto Restart;
- допустимую погрешность жидкости.

Управление:

- `1-5` — выбрать поле;
- `A/D` — изменить значение;
- `S` — сохранить;
- `R` — заново открыть Setup для переназначения транспозеров;
- `B` — назад.

## Важное

Экран конфигурации пока изменяет сохранённый профиль HUB. Он не записывает значения `setParameters()` непосредственно в контроллер EOH. Физическое сопоставление транспозера / стороны / tank по-прежнему меняется через Setup.

Обновление через `/home/U.lua` не должно удалять пользовательский `registry.dat`, настройки и логи.
